# TMW Registration Portal User Guide

This guide explains how to register one member, submit a ward batch sheet, use coordinator views, and print a form. The portal can be used from a computer, tablet, or phone.

## Before you begin

- Use the member's accurate details and confirm them before submitting.
- Collect and use personal information only for authorised TMW registration and coordination. Obtain the member's consent and keep their details secure.
- Treat voter identification and bank account information as sensitive. Do not share screenshots, printed forms, or downloaded files with unauthorised people.
- A successful on-screen confirmation is the indication that the portal accepted a submission. If you see an error, correct any highlighted details and try again; avoid submitting repeatedly while a request is still in progress.

## Portal navigation

The main navigation offers:

- **Single Member Form** — register one person.
- **Ward Sheet (Batch 20-Rows)** — enter multiple members for the same ward and submit them together.
- **State Coordinators** — open a state-specific coordinator login.
- **Print Official Form (PDF)** — prepare a printable blank form.

The coordinator login for the national directory is separate from the state coordinator login and appears in the page footer as **Coordinator Login**.

## Register one member

1. Open **Single Member Form**.
2. Select the member's **State**, **LGA**, and **Ward**. Choose the correct location; the LGA and ward options depend on the selected location.
3. Choose whether the person is an **EXCO** member or a **Non-EXCO** member, then select the applicable role. If you select an “Other” role, enter its title.
4. Enter the member information:
   - Full name, in surname-first order.
   - Active phone number.
   - Voter's Card Number (VIN), as shown on the card.
   - Polling unit name or code.
5. Select the bank. If the bank is not in the list, choose **Other / Microfinance Bank** and enter its name. Enter the 10-digit account number carefully.
6. Enter the registrant's or coordinator's name in the signature field if required, and ensure the consent box is checked after obtaining consent.
7. Review the details and select **Submit Ward Registration**. Wait for the submission result; do not close the page while it is submitting.
8. On success, review the registration slip and reference number. Use **Print Slip / Save PDF** if you need a copy, or choose **New Registration** to start another form.

Fields marked with an asterisk are required. The form checks required information and the account number length and may show a VIN format check. If a validation message appears, correct the information before submitting. **Clear Form** resets the current form.

## Submit a ward batch sheet

Use the batch sheet when registering several people from the same ward.

1. Open **Ward Sheet (Batch 20-Rows)**.
2. Set the shared sheet details: **State**, **LGA**, **Ward**, **Coordinator Name**, and **Submission Date**.
3. Complete one member per row. Enter each person's name, EXCO status and role, phone, VIN, polling unit, bank, account number, and signature as requested.
4. The sheet starts with 20 rows. Use **Add 5 More Rows** for more members. The active-row counter shows how many rows contain member information.
5. **Fill Sample Data** is for demonstrating the layout only. Clear sample entries and replace them with verified member details before submitting.
6. Review the shared location and every completed row. Use **Submit Ward Sheet** and wait for the success or error message. The button indicates the number of members being submitted.
7. To make a paper copy, select **Print / Export PDF Sheet**. Review the print preview, then select **Print Sheet (or Save as PDF)**. Use your browser's print dialog to choose a printer or save a PDF.
8. **Clear Sheet** removes the current sheet entries. Use it only when you intend to start over.

## State coordinator access

State coordinators can view registrations for the state selected at login; this view is not the national directory.

1. Select **State Coordinators** in the main navigation.
2. Choose your state and enter that state's coordinator PIN, then select **Login**.
3. If the state is still using its initial PIN, the portal requires the coordinator to change it before opening the list. The initial PIN is **0000** unless a different PIN has already been configured. Choose a private PIN and do not share it.
4. In the state registry, use the search box to search by name, phone, LGA, ward, or reference. Select **Refresh** to load the latest registrations.
5. Use **Change PIN** to update your PIN. Select **Exit** when finished, especially on a shared device.

If login fails, check that you selected the correct state and entered its current PIN. Contact the portal administrator if the PIN is unknown or login still fails.

## National coordinator directory

The national coordinator directory is for authorised national coordinators and can show registrations across states. State coordinator accounts do not provide access to this all-state view.

1. Select **Coordinator Login** in the page footer, enter the national coordinator PIN, and log in.
2. Use the search field and the role and sync-status filters to narrow the list.
3. Select **Refresh Now** or **Fetch Latest** to load recent registrations from the central sheet. **Export CSV** downloads the currently available directory records.
4. Select **Exit Coordinator Mode** when finished, particularly on a shared device.

The national directory also has a control to clear the local device cache. This is not a routine refresh action; use it only if you intend to clear data cached on that device.

## Print a blank official form

Select **Print Official Form (PDF)** in the main navigation. In the print preview, choose **Back** to return to the portal or **Print Sheet (or Save as PDF)** to print or save a copy through your browser.

## If something does not work

- Check that required fields are filled in and that the phone, VIN, bank, and account details are entered correctly.
- Wait for any in-progress submission to finish and read the message shown on the form.
- If a successful confirmation does not appear, do not assume the registration was received. Retry only after checking the result and, if needed, ask an authorised coordinator to verify the entry.
- If a coordinator login or data refresh repeatedly fails, contact the portal administrator rather than sharing a PIN or member information in a public channel.
